# Python for Absolute Beginners 🐍

**A hands-on Python learning path for students who are starting from zero.**

**Created and taught by [Abdullah Niaz](https://github.com/Abdullah-Niaz)****Repository:** [Python-For-Absolute-Begginers](https://github.com/Abdullah-Niaz/Python-For-Absolute-Begginers)

> **Welcome!** You do not need previous programming experience. Start with the first notebook, type and run the examples, change the code, and practise regularly. Mistakes and debugging are part of learning.

## What you will learn

By working through the notebooks and practice activities, you will begin to:

- Understand variables, types, strings, booleans and operators.
- Use lists, tuples, sets and dictionaries to organise data.
- Make decisions with conditions and repeat tasks with loops.
- Break problems into functions and understand basic scope.
- Use Python's built-in modules, dates, mathematics, JSON, regular expressions and `pip`.
- Handle errors and work with simple text files.
- Create and use basic classes and objects.
- Write small, readable programs and explain how they work.

**Level:** Absolute beginner
**Suggested learning plan:** 8 weeks, with four teaching/practice days, one assessment day and two rest days each week.
**Format:** Jupyter Notebooks (`.ipynb`) plus a few supplementary Python/example files.

## Get started

### 1. Install the tools

Install:

1. [Python 3](https://www.python.org/downloads/) (a currently supported version).
2. [Visual Studio Code](https://code.visualstudio.com/) with the Python and Jupyter extensions, **or** [JupyterLab](https://jupyter.org/).
3. [Git](https://git-scm.com/downloads) if you want to clone the repository.

On Windows, enable **Add Python to PATH** during installation if the installer offers it.

Check Python in a terminal:

```bash
python --version
```

On some systems, use `python3 --version` (or `py --version` on Windows).

### 2. Get the course files

Clone the repository:

```bash
git clone https://github.com/Abdullah-Niaz/Python-For-Absolute-Begginers.git
cd Python-For-Absolute-Begginers
```

**No Git yet?** Open the repository page, choose **Code → Download ZIP**, extract the ZIP, and open the extracted folder.

### 3. Open the notebooks

**Option A — VS Code:** Open the folder, select `01. Variables.ipynb`, choose a Python kernel and run cells one at a time.

**Option B — JupyterLab:** In the project folder, install and launch JupyterLab:

```bash
python -m pip install jupyterlab
python -m jupyter lab
```

Open `01. Variables.ipynb` in the browser window that starts. If `python` is not recognised, use `python3` or `py` as appropriate to your system.

### 4. How to study each notebook

1. Read the explanation before running the code.
2. Predict what a cell will print.
3. Run the cell and compare the result with your prediction.
4. Change at least one input, value or condition and rerun it.
5. Re-create the key example **without copying** it.
6. Finish a small practice task and save your work separately.
7. Make a note of what confused you and ask about it during review.

> **Notebook tip:** Running a cell can change the current session's state. If the result looks confusing, restart the kernel and run the cells again from top to bottom. Some older notebook examples may require small adjustments for your installed Python environment.

## How to submit assignments

Create a separate folder for each week to avoid editing the original lesson notebooks directly:

```text
my-python-practice/
├── week-01/
│   ├── personal_intro.py
│   └── README.md
├── week-02/
├── week-03/
├── ...
└── final-project/
    ├── main.py
    └── README.md
```

For each submission, include:

- **What you built** (two or three sentences).
- **How to run it** (the command or notebook name).
- **What you learned** and one challenge you solved.
- Your code and, when helpful, a screenshot or sample terminal output.

During Friday reviews, be prepared to explain your own code, change one requirement live, and debug an unexpected result.

## Common beginner questions

**Do I need experience?** No. This course starts with basic concepts.

**Can I learn by only watching?** Watching helps, but typing and changing code is necessary to learn problem-solving.

**What if a notebook shows a saved output that differs from what I see?** Rerun the cells in order, inspect the input values, and ask for help. Saved notebook outputs may come from earlier executions.

**Do I need to learn Django or AI right now?** No. This course focuses on Python foundations and introductory OOP. DSA, Django, FastAPI, LLM integration and RAG are later learning stages.

**Can I use AI coding tools?** You can use them to ask for explanations or debugging hints, but make sure you can write and explain the final solution yourself.
